## 📌 Descripción

Este proyecto consiste en el desarrollo de una aplicación de consola utilizando el lenguaje de programación **Dart**, con el objetivo de implementar las operaciones básicas de un sistema **CRUD** para la gestión de productos de una tienda.

La aplicación permite al usuario administrar un catálogo de productos mediante un menú interactivo en la consola.

Las operaciones principales implementadas son:

- ➕ Agregar productos.
- 📋 Listar productos.
- ✏️ Actualizar productos.
- 🗑️ Eliminar productos.
- 🚪 Salir del programa.

El proyecto también permite poner en práctica el manejo de listas, clases, métodos, estructuras de control, entrada de datos por consola y organización del código en diferentes archivos.

---

## 🎯 Objetivo

Desarrollar una aplicación CRUD en Dart que permita gestionar productos de manera sencilla mediante una interfaz de consola, aplicando conceptos fundamentales de programación y utilizando **GitFlow** para organizar el desarrollo de las diferentes funcionalidades.
